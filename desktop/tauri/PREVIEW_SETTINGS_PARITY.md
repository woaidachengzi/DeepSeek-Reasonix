# Preview settings parity with Reasonix 1.38.3

This inventory compares the stable desktop settings navigation in
`desktop/frontend/src/components/SettingsNavigation.tsx` with the Tauri Preview
settings in `desktop/frontend/src/tauri/TauriSettings.tsx`. It records what the
Preview settings UI actually reads or changes as of 2026-09-28. “Not in settings”
does not imply that the Go runtime lacks the underlying capability.

| Stable section | Tauri Preview status | Current behavior / missing work |
| --- | --- | --- |
| General | Partial | Appearance mode, conversation width, text size, standard/deep process disclosure, notifications, completion/attention sounds and volume, macOS close behavior, and new-session default tool approval work. The Preview bottom status bar shows available workspace, default model, current-session state and bridge connection. Its authenticated session snapshot also provides the current controller's context gauge, compaction threshold, and session cache hit/miss counts; those values refresh on open, turn completion, and manual refresh. Token counters remain explicitly “observed” from the current synchronized event stream and hide until a usage event arrives, because a complete historical session token total is not available. Icon/text style, visibility, and order persist locally. Stable full-session token totals and cost items remain unavailable without a verified session source. Language is not exposed because Preview workspace/settings strings still contain fixed Chinese text and would not switch with `LocaleProvider`. Currency is not exposed because Preview does not yet render a converted cost value. The bridge samples the saved approval default when it opens a fresh transcript and records the session posture after a completed snapshot. |
| Model preferences | Partial | Default, planner, image-understanding fallback, and native web-search models are read and saved through the authenticated bridge for new conversations. Planner choices require a ready provider; explicit image choices require confirmed image-input support; search choices require an enabled, ready native search route. Project configuration can override these global preferences. Stable advanced model assignments and live current-session switching are not present. |
| Model services | Partial | Provider readiness and model counts are shown; required API keys can be saved to or deleted from the system keychain. Preview can add OpenAI Chat, Anthropic Messages, or Responses services, edit labels/endpoints/model lists/defaults, and delete custom services with a saved-configuration check and default-model fallback. The core curated preset catalog is available for review and install, including multi-route presets; installation preserves preset model metadata, refuses conflicting names, and saves to the Preview profile with a config revision check. Existing configured endpoints and credential identifiers are deliberately not returned to the WebView; public preset endpoints are shown before installation. Advanced provider controls, preset reset, model discovery, and richer status diagnostics are not in settings yet. Official DeepSeek access cannot be deleted from this page. |
| Usage statistics | Available for Preview data | The stable usage charts read the Preview profile's recorded token and turn statistics through an authenticated bridge query. Source filters are All and Tauri Preview; the stable profile's historical statistics remain separate. |
| Bots | Not in settings | No Preview bot-management view or verified mutation contract. |
| MCP and tools | Partial | Global and project MCP servers can be listed, added, edited, and deleted through the native bridge. The effective enabled state can be toggled through the core activation store, including package-managed servers; new sessions consume that state and an idle current session can explicitly reload it. The official MCP Registry can be searched on demand; choosing an installable entry re-fetches live metadata and opens a reviewed add form. Offline cache supports browsing but cannot be used to install. For the matching active workspace, the page reads current-session Host connection/starting/failure status and bounded tool names/descriptions without starting servers or exposing schemas/results. Stable reconnect/authentication actions, richer diagnostics, and other tool settings are not represented. |
| Remote SSH | Not in settings | No Preview remote-management view or verified host contract. |
| Agent Skills | Partial | Preview discovers skills and sources for the selected workspace using the same skill store as the core runtime. A native folder picker selects custom sources. The authenticated bridge saves automatic-invocation policy, per-name enablement, and source additions/removals/toggles to either global config or the selected project's `reasonix.toml`, using strict, locked edits; an idle current session can explicitly reload. Controls show the saved value for the selected scope and flag project overrides, while the inventory reports global/project source ownership. Project overrides follow core config layering, so the first project edit to a list copies its inherited global values into an explicit project override. The Tauri host now serializes the scope and project-override fields used by these controls. Stable per-root skill inventory and dependency/availability diagnostics are not present. |
| Subagents | Partial | Preview lists discoverable subagent profiles for the selected workspace and saves global default model, reasoning effort, delegation depth, concurrency limits, and per-profile model/effort overrides through the authenticated bridge. It can create global or project manual profiles and edit/delete eligible profile files with revision checks. Profiles carrying unmanaged frontmatter or extra files are preserved for direct skill-folder editing. New sessions use the saved values; an idle current session can explicitly reload. Project configuration may override global defaults. Stable Try execution and richer profile diagnostics are not yet available. |
| Plugins | Not in settings | No Preview plugin-management view or verified mutation contract. |
| Memory | Partial | Preview reads discovered standing instruction documents and saved facts/archives for the selected workspace from the core memory store. It can edit whitelisted documents with revision checks, append notes by scope, archive facts, and restore them through an authenticated bridge. New sessions read the changes; an idle current session can explicitly reload. Stable recall traces, suggestions, document history, and structured fact editing are not yet present. |
| Hooks | Available for new sessions | Preview reads and edits global or selected-project `settings.json` hooks through the authenticated bridge, validates events and commands, preserves unrelated settings fields, and refuses to overwrite a file changed since it was read. New sessions load saved hooks; an idle current session can explicitly reload. The Preview editor exposes JSON rather than the stable structured controls, and does not include imported plugin-hook diagnostics. |
| Diagnostics | Partial | Bridge health/restart and session catalog audit/refresh are available in settings. The existing runtime drawer also contains event logs and session details. |
| Shortcuts | Read only | The active Preview keyboard shortcuts are listed; shortcut customization is not implemented. |
| Permissions | Available for new sessions | The Preview settings page reads and saves the global writer fallback mode and allow/ask/deny tool rules through the authenticated bridge, preserving unrelated config fields. It can explicitly restart an idle current session to apply the saved policy. Workspace-level rules may override the global profile. |
| Sandbox | Available for new sessions | Preview reads and saves Bash isolation mode, sandbox network egress, workspace root, and extra writable directories through the authenticated bridge. An idle current session can explicitly reload the saved configuration. Stable shell selection and effective write-root display are not present. Project configuration can override global values. |
| Network | Available for new sessions | Preview reads and saves ordinary HTTP proxy mode, custom proxy type/server/port/username, no-proxy hosts, proxy URL, and password through the authenticated bridge. Existing URL and password are write-only in the WebView and can be explicitly cleared. An idle current session can reload the saved configuration. Live proxy checks and stable update-network integration are not present. |
| Appearance | Partial | Theme mode/style, conversation width, text size, UI font, and code font persist locally. Remaining stable appearance controls are not present. |
| Storage | Partial | Preview profile location, backup-before-import, project-folder import, and unclaimed session review are available in the Data tab. Broader stable storage management is not present. |
| Updates | Not in settings | No Preview update settings UI or verified updater flow in this page. |

## Implementation rule

Add a control only with an identified source of truth, a read path, a save or
action path where appropriate, and an observable result or error. Keep unsupported
stable categories out of the Preview navigation until those paths exist. The
Preview profile and host preferences remain separate from the stable user profile.

# 蓝色小鲸鱼操作指示器

macOS 版的电脑控制提供两处显示：目标应用窗口上的短暂透明浮层，以及
Reasonix 画中画中的落点标记。图案前端的小圆点对应系统读回的真实鼠标位置，
鲸鱼身体偏向右下方。确认发送过坐标鼠标点击、且读回位置仍匹配时会显示蓝色波纹。

指示器只使用已授权应用的原生观察结果，不使用模型猜测的目标坐标。不增加模型
调用，也不负责点击、输入、批准操作或改变系统鼠标设置。键盘/AX 动作不会伪造
鼠标点击反馈；无有效位置时不显示鲸鱼。

## 显示生命周期

- 原生侧只接受认证 bridge 的实时 computer_use 预览事件；没有新增渲染器控制接口。
- 浮层在主线程绘制，透明、非激活、鼠标穿透。窗口截图仍只捕获被批准的目标窗口。
- 每个位置样本最多显示约 1.3 秒；用户移动鼠标、切换应用、鼠标下方窗口变化，
  下一步工具操作、任务结束或取消都会隐藏旧指示器。不会虚构鼠标移动轨迹。
- 动画属于会话、turn 和 generation；旧回调不能覆盖新位置，取消前首张预览尚未
  到达也会阻止迟到显示。新用户回合可重新显示。
- 事件订阅替换时重置显示序号与普通回合记录，隔离旧订阅的排队事件和动画；
  桥接重启、快照重同步后可继续显示，已取消和已完成回合的拦截仍保留。
- 画中画将归一化落点映射到原始图像纵横比，保留上下/左右留黑区域；支持浅色、
  深色、窄窗口、折叠和停止。请求减少动画时保留静态点击环。

位置与标记从原始回执状态分离：鼠标展示数据变化不使观察回执失效，也不会把
普通位置样本变成 move/confirm_click 的操作凭证。点击前的权限、窗口身份、
内容状态、原生命中检测和单次回执校验保持原有行为。

## 开发检查

唯一图案源为 `desktop/tauri/resources/blue-whale-cursor.svg`，由 AppKit 和前端
共用，避免两个光标的热点或图案不一致。

原生浮层的独立本地验收程序使用生产绘制代码，只创建自己的窗口，不发送输入：

```sh
cargo run --manifest-path desktop/tauri/Cargo.toml \
  --example blue_whale_cursor_qa --features cursor-qa -- /tmp/whale-native.png
```

`cursor-qa` 只为该显式示例启用，不是正常安装包的功能开关。它检查原生图案绘制、
下层窗口命中和焦点保持，输出自身视图的 PNG；不使用真实邮箱或系统截图权限。
控制器、协议镜像和原生生命周期测试另外覆盖展示事实、无假点击、负坐标屏幕、
重复/迟到事件以及取消前后的归属。

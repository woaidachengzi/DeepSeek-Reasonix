# 当前候选实际菜单与按键操作

全新 explicit 私有档案，CUA 操作当前 d1 实际安装包。Cmd+逗号打开设置；实际 View 全屏菜单进入全屏，截图从 2560×1640 变为3840×2160且标题栏按钮消失；Ctrl+Cmd+F 恢复普通窗口/标题栏按钮。实际 Quit 菜单退出后 kernel/open 0，无 sidecar/ready 残留。

实际点击 Window > Minimize 后两次截图均是缩小变换画面，AX仍保留标准窗口；只读WindowServer元数据仍列主窗口onscreen，未取得权威isMiniaturized。保留这次不确定现场，不能算物理最小化成功。实际 Show Reasonix 返回完整普通窗口。此处观察仅为本会话工具操作及AX/截图转录摘要，没有另存截图。全屏和退出的成功不能替代托盘、Dock、显示器等未验项目。

# macOS D：默认档案目录拒绝与安装验收

2026-10-02。D 未结案，E 未推进。没有新增延期确认或发布授权。

## 问题与修复

原初始化使用 `create_dir_all(reasonix-core)`，会跟随默认目录的符号链接。
链接到旧 Wails `.reasonix` 时，独立默认目录约定被绕过。确定性回归在旧逻辑失败；
上一轮真实安装包也在私有旧档案中修改了配置，并生成 Preview 凭据身份文件。
全部夹具只含固定假数据，未操作用户的旧档案。

现在创建应用数据容器后，只创建默认档案叶目录，并用 `symlink_metadata` 检查普通目录。
已有链接、悬空链接和普通文件均拒绝；新目录以 0700 创建，正常已有档案内容保持。
显式 `REASONIX_HOME` 的覆盖及继承 state/cache 的既有语义未改变。

安装验收还发现已知目录拒绝进入 Tauri setup 错误路径后会 SIGABRT。
仅把 `build().expect` 改为普通错误退出不能修复该路径：当前 Tauri 在运行事件循环的
Ready 回调中执行 setup，并对 setup Err 调用 panic。中间包的日志明确记录 exit=-6、
expectedMessage=true，未把原件保护等同于正常失败退出通过。
最终在档案配置拒绝时、创建 WebView/sidecar 之前输出恢复说明并以退出码 1 结束；
应用构造错误也改为普通非零退出。此修复不承诺其他所有 setup 失败都已迁移为正常退出。

## 边界与剩余门禁

这是默认叶目录的启动检查，不是抵御任意外部目录替换的生命周期锁。
不能推广为显式共享目录、无锁协议的旧稳定宿主、全量历史/附件/检查点或数据回退已验收。
旧版目录互斥、历史偶发窗口失败、实际托盘/Dock/IME/通知/钥匙串等交互及 A/B/C/E、
Developer ID 签名/公证仍遵循迁移清单。本轮原生 UI 工具再次连接超时并重置，物理交互
没有新增通过记录。没有正式发布或切换默认下载项。

重跑最终安装包的边界：

```sh
python3 -B tools/tauri/smoke-managed-profile-boundary.py '/path/to/Reasonix Tauri Preview.app'
```

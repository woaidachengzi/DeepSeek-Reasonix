# 空输入继续运行

2026-10-14：已有且成功读取的对话，输入框无文字、选中文本或附件时，发送按钮提供“继续运行”（快捷键沿用发送快捷键）。新对话仍要求输入；运行中显示停止，等待审批时不能绕过提示直接继续。

模型选择或请求失败后，可以先换成可用模型，再直接点击继续。操作沿用当前模型和已有上下文，不追加可见的“继续”用户消息，不删除先前回答或重放已经完成的工具操作。重新调用模型仍可能消耗服务商额度。

后端使用独立的 `:continue` 幂等命令，按精确会话 ID 路由。只有空闲实例及真实用户历史才能继续；新控制器沿用原策略来源，排除宿主元数据和固定上下文修订。继续指令具有持久宿主来源，公开历史将其隐藏，不创建新的可见回退检查点。

本批 15 个文件，review 关注命令幂等、来源与权限约束、同会话准入、后台隔离和无消息 UI。完整 Go control／desktopbridge／sidecar race、Rust 320 项（6 项原有忽略）和 Tauri 前端回归通过。实际控制器通过 HTTP 继续、同请求 ID 重试后，用户消息数仍为 1；组件验证空输入继续只作用于目标，空白新对话保持禁用。
